Create a Lead in Zoho CRM after each call.

## Before you start
- A Zoho CRM account.
- You need a refresh token from the Zoho API console (a “self client”).
- Workspace role of **Developer** or above.

## What you will enter
| Field | Secret? | Required? | Hint |
|---|---|---|---|
| Client ID | Yes | Required | — |
| Client secret | Yes | Required | — |
| Refresh token | Yes | Required | From the Zoho API console (self client). |
| Zoho region | No | Optional (default: in) | in, com, eu or com.au |

Secret fields are hidden after you save them and never shown again.

## Steps
1. Open **Integrations** (or **Tools**) and choose **Zoho CRM**.
2. Fill in the fields above.
3. Press **Connect**. We check the details with Zoho CRM before saving. If they are wrong you will see a plain message; fix the field and try again.
4. Open your agent, go to its tools, and switch on Zoho CRM.
5. Go live again so the live copy of the agent gets the connection.

## What the agent can do on a call
Nothing during the call. This connection works after the call ends.

## What gets sent after each call
Swarvo AI sends a new Lead for the caller.

## If something goes wrong
| Symptom | What to do |
|---|---|
| “Zoho CRM did not accept those details. Check them and try again.” | Copy the values again from Zoho CRM. Check for stray spaces. |
| “Zoho CRM said no (…)” followed by a number | Zoho CRM refused the request. Check the permissions you gave the token or app. |
| It connects but nothing arrives | Make sure the agent has the connection switched on and that you pressed **Go live** afterwards. |

:::caution
You need a refresh token from the Zoho API console (a “self client”).
:::
