Send each caller a follow-up WhatsApp message after the call.

## Before you start
- A WhatsApp account.
- WhatsApp only lets you start a chat with a message template that Meta has approved. Use the approved template’s exact name.
- Workspace role of **Developer** or above.

## What you will enter
| Field | Secret? | Required? | Hint |
|---|---|---|---|
| Phone number ID | No | Required | Meta for Developers → WhatsApp → API setup. |
| Access token | Yes | Required | — |
| Approved template name | No | Required | Messages outside a chat need a template Meta has approved. |
| Template language | No | Optional (default: en) | — |
| Template has the caller's name in \{\{1\}\}? (yes/no) | No | Optional (default: no) | — |

Secret fields are hidden after you save them and never shown again.

## Steps
1. Open **Integrations** (or **Tools**) and choose **WhatsApp**.
2. Fill in the fields above.
3. Press **Connect**. We check the details with WhatsApp before saving. If they are wrong you will see a plain message; fix the field and try again.
4. Open your agent, go to its tools, and switch on WhatsApp.
5. Go live again so the live copy of the agent gets the connection.

## What the agent can do on a call
Nothing during the call. This connection works after the call ends.

## What gets sent after each call
Swarvo AI sends your approved template to the caller’s number.

## If something goes wrong
| Symptom | What to do |
|---|---|
| “WhatsApp did not accept those details. Check them and try again.” | Copy the values again from WhatsApp. Check for stray spaces. |
| “WhatsApp said no (…)” followed by a number | WhatsApp refused the request. Check the permissions you gave the token or app. |
| It connects but nothing arrives | Make sure the agent has the connection switched on and that you pressed **Go live** afterwards. |
