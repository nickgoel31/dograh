This is a **web tool**: the agent sends a request to an address you give it.

## Steps
1. Open **Tools & Integrations** and add a web tool.
2. Enter the address, the method, headers and the parameters the agent should send.
3. Press **Test this tool**. Private and internal addresses are refused.
4. Attach the tool to the agent and go live again.

Secret headers are stored safely and shown as dots.
