## Before you start
- A Cal.com account and an event type.

## What you will enter
| Field | Required |
|---|---|
| API key | Yes (at least 10 characters) |
| Event type number | Yes |
| Time zone | Optional, default Asia/Kolkata |

## Steps
Open **Tools & Integrations**, choose **Cal.com**, enter the fields and connect. If it fails you will see "We couldn't connect to Cal.com with those details. Check the API key and the event type number."

## What the agent can do
Check free times on a day and book a time with the caller's name, phone and email.
