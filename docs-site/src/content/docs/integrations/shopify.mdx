Let the agent look up an order and say where it is.

## Before you start
- A Shopify account.
- The access token must allow reading orders.
- Workspace role of **Developer** or above.

## What you will enter
| Field | Secret? | Required? | Hint |
|---|---|---|---|
| Store address | No | Required | yourstore.myshopify.com |
| Admin API access token | Yes | Required | Shopify admin → Apps → Develop apps. Allow reading orders. |

Secret fields are hidden after you save them and never shown again.

## Steps
1. Open **Integrations** (or **Tools**) and choose **Shopify**.
2. Fill in the fields above.
3. Press **Connect**. We check the details with Shopify before saving. If they are wrong you will see a plain message; fix the field and try again.
4. Open your agent, go to its tools, and switch on Shopify.
5. Go live again so the live copy of the agent gets the connection.

## What the agent can do on a call
- **Look up an order**: Look up a customer's order by its number and tell them its payment and shipping status.

## What gets sent after each call
Nothing is sent automatically after a call.

## If something goes wrong
| Symptom | What to do |
|---|---|
| “Shopify did not accept those details. Check them and try again.” | Copy the values again from Shopify. Check for stray spaces. |
| “Shopify said no (…)” followed by a number | Shopify refused the request. Check the permissions you gave the token or app. |
| It connects but nothing arrives | Make sure the agent has the connection switched on and that you pressed **Go live** afterwards. |

:::caution
The access token must allow reading orders.
:::
