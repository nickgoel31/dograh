Check free times and book into a Calendly event.

## Before you start
- A Calendly account.
- Booking needs a paid Calendly plan. Calendly also needs the caller’s email address to book.
- Workspace role of **Developer** or above.

## What you will enter
| Field | Secret? | Required? | Hint |
|---|---|---|---|
| Personal access token | Yes | Required | Calendly → Integrations → API & Webhooks → Personal access tokens. Booking needs a paid Calendly plan. |
| Event type link | No | Required | The event's API address, like https://api.calendly.com/event_types/XXXX (see Calendly's event types API). |
| Time zone | No | Optional (default: Asia/Kolkata) | — |

Secret fields are hidden after you save them and never shown again.

## Steps
1. Open **Integrations** (or **Tools**) and choose **Calendly**.
2. Fill in the fields above.
3. Press **Connect**. We check the details with Calendly before saving. If they are wrong you will see a plain message; fix the field and try again.
4. Open your agent, go to its tools, and switch on Calendly.
5. Go live again so the live copy of the agent gets the connection.

## What the agent can do on a call
- **Check free appointment times**: Check which appointment times are free on a given day.
- **Book an appointment**: Book an appointment once the caller agreed a time. Calendly needs the caller's email.

## What gets sent after each call
Nothing is sent automatically after a call.

## If something goes wrong
| Symptom | What to do |
|---|---|
| “Calendly did not accept those details. Check them and try again.” | Copy the values again from Calendly. Check for stray spaces. |
| “Calendly said no (…)” followed by a number | Calendly refused the request. Check the permissions you gave the token or app. |
| It connects but nothing arrives | Make sure the agent has the connection switched on and that you pressed **Go live** afterwards. |

:::caution
