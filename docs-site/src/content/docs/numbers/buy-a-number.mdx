## Before you start
- Your workspace must be in **Live** mode to buy a real number. In Test mode you get sandbox numbers that never ring.
- Money in your wallet.

## Steps
1. Open **Phone Numbers**.
2. Choose a country and a kind: **Local** or **Toll-free**. Optionally type digits you would like the number to contain.
3. Press search and pick a number. The monthly rent is shown with the number.
4. Buy it.
5. Choose which agent should answer it.

## What you should see
The number appears in your list attached to the agent. Call it from another phone to check.

## Rent
A number's monthly rent is billed separately from call minutes. See [How billing works](/billing/how-billing-works/).

## If something goes wrong
- "We bought the number but couldn't save it. We've released it; please try again." The purchase was undone. Try again.
- Some numbers, especially in India, need identity documents before they are switched on. If that applies you will be told what to do.
- Live numbers attach only to agents that are live.
