If you already own a phone number with a carrier, you can connect it instead of buying a new one. Swarvo AI answers calls to that number with the agent you choose.

## Before you start
- An account with one of the carriers below, and a number in it.
- The carrier details listed for your carrier (they are shown as fields in **Phone numbers → Bring your own number**).
- Your workspace must be in **Live** mode. Test mode uses sandbox numbers only.

## Two kinds of carrier
- **We set the incoming-call address for you:** Twilio and Plivo. After you save, nothing else is needed on the carrier side.
- **You set the incoming-call address:** Vobiz, Telnyx, Vonage, Cloudonix, Asterisk (SIP). After you save, you open your carrier's dashboard and point the number's incoming calls at the address Swarvo AI shows you. It looks like `https://YOUR-API-ADDRESS/api/v1/telephony/inbound/run`.

## What each carrier needs
### Twilio
We set the incoming-call address for you.

| Field | What it is | Secret? | Required? |
|---|---|---|---|
| Account SID | `account_sid` | No | Required |
| Auth token | `auth_token` | Yes, hidden after saving | Required |

### Plivo
We set the incoming-call address for you.

| Field | What it is | Secret? | Required? |
|---|---|---|---|
| Auth ID | `auth_id` | No | Required |
| Auth token | `auth_token` | Yes, hidden after saving | Required |

### Vobiz
You set the incoming-call address in your carrier dashboard.

| Field | What it is | Secret? | Required? |
|---|---|---|---|
| Account ID | `auth_id` | No | Required |
| Auth token | `auth_token` | Yes, hidden after saving | Required |
| Application ID | `application_id` | No | Optional |

### Telnyx
You set the incoming-call address in your carrier dashboard.

| Field | What it is | Secret? | Required? |
|---|---|---|---|
| API key | `api_key` | Yes, hidden after saving | Required |
| Connection ID | `connection_id` | No | Optional |

### Vonage
You set the incoming-call address in your carrier dashboard.

| Field | What it is | Secret? | Required? |
|---|---|---|---|
| API key | `api_key` | No | Required |
| API secret | `api_secret` | Yes, hidden after saving | Required |
| Application ID | `application_id` | No | Required |
| Private key | `private_key` | Yes, hidden after saving | Required |

### Cloudonix
You set the incoming-call address in your carrier dashboard.

| Field | What it is | Secret? | Required? |
|---|---|---|---|
| Bearer token | `bearer_token` | Yes, hidden after saving | Required |
| Domain ID | `domain_id` | No | Required |

### Asterisk (SIP)
You set the incoming-call address in your carrier dashboard.

| Field | What it is | Secret? | Required? |
|---|---|---|---|
| Asterisk address (ARI) | `ari_endpoint` | No | Required |
| ARI application name | `app_name` | No | Required |
| ARI password | `app_password` | Yes, hidden after saving | Required |
| WebSocket client name | `ws_client_name` | No | Optional |


## Steps
1. Open **Phone numbers** and press **Bring your own number**.
2. Choose your carrier.
3. Type the number with its country code, for example `+919800000000`.
4. Fill in the carrier fields from the table above.
5. Press **Connect**.
6. For a carrier where **you** set the address: open the carrier's dashboard, find the number (or application), and set its incoming-call address to the one shown.
7. Pick the agent that should answer, then call the number from another phone to check.

## What you should see
The number appears in your list as connected and attached to your agent. Calling it reaches the agent.

## If something goes wrong
| Symptom | Likely cause | What to do |
|---|---|---|
| "Connect" says the details were not accepted | Wrong ID, token or secret | Copy the values again from the carrier dashboard. Check for spaces. |
| Connected, but the number does not ring the agent | You have not set the incoming-call address (carriers where you set it) | Set it in the carrier dashboard, then call again. |
| Rings, then silence or a busy tone | Number not attached to a live agent, or outside call hours | Attach the number to a **live** agent and check [call hours](/numbers/call-hours-and-fallback/). |
| A callers hears an "after hours" message | The number is closed right now | Change the opening hours. |
| Call is refused with a balance message | Wallet is empty | [Add money](/billing/adding-money/). |
