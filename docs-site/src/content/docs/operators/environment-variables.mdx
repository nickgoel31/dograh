This page is for the person hosting Swarvo AI. Customers can ignore it.
:::

Set these in the `.env` file used by `docker-compose.yaml`, then restart the API. The list was produced by searching the product code (44 names).

| Variable | What it does | Required? | If missing |
|---|---|---|---|
| `CURRENCY` | Currency code. Default `INR`. | Optional | — |
| `GOOGLE_API_KEY` | Key for the Google voice engine, read by the profile-setup helper. | Optional | Google voices are unavailable. |
| `GOOGLE_CLIENT_ID` | Google sign-in client id. | Optional | The “Sign in with Google” button is hidden. |
| `HUMAN_COST_PER_MIN_DEFAULT` | Starting value for “cost of a person per minute” in Analytics. | Optional | Default 5. |
| `INWORLD_API_KEY` | Key for the Studio voice engine, read by the profile-setup helper. | Required for Studio voices | Studio voices are unavailable. |
| `PRICE_PER_MIN` | Fallback per-minute price. The real price comes from the volume bands. | Optional | Default 6.75. |
| `PRODUCT_ALLOWED_ORIGINS` | Comma-separated website origins allowed to open browser call sockets, for example `https://app.swarvoai.com`. | Required | Practice calls close at once with `origin_not_allowed`. |
| `PRODUCT_ALLOW_PRIVATE_WEBHOOKS` | `true` lets webhooks use http and private addresses. Development only. | Optional | Keep unset in production. |
| `PRODUCT_APP_URL` | Where the new app lives, used for links in emails, for example `https://app.swarvoai.com/new`. | Required for email links | Emailed links (top-up, invites) are missing or wrong. |
| `PRODUCT_CALL_WINDOW` | Campaign calling window in contacts’ local time. | Optional | Default 09:00 to 21:00. |
| `PRODUCT_COOKIE_SAMESITE` | SameSite setting of the cookie. Default `lax`. | Optional | — |
| `PRODUCT_COOKIE_SECURE` | `true` sends the sign-in cookie over https only. Keep `true` in production. | Optional | Sign-in fails over plain http if left `true`. |
| `PRODUCT_EMAIL_FROM` | “From” line, for example `Swarvo AI <hello@swarvoai.com>`. | Optional | Built from the SMTP user. |
| `PRODUCT_FREE_MINUTES` | Free minutes granted once to each new workspace. Default 0. | Optional | New workspaces start with 0 minutes. |
| `PRODUCT_GOOGLE_SA_JSON` | Google service account (JSON) used for Calendar and Sheets. | Required for those integrations | “Google isn’t switched on for this platform yet. Ask support to turn it on.” |
| `PRODUCT_GST_RATE` | GST percentage on invoices. Default 18. | Optional | — |
| `PRODUCT_INVOICE_SAC` | SAC code printed on invoices. | Optional | Have your accountant confirm the value. |
| `PRODUCT_INWORLD_MODELS` | JSON map that overrides which AI model each Brain level uses on the Studio voice engine. | Optional | Built-in defaults are used. |
| `PRODUCT_MAX_CAMPAIGN_ROWS` | Largest contact list a campaign accepts. | Optional | Default 10,000. |
| `PRODUCT_NAME` | Brand name shown in emails, webhook signature header and the website button. | Optional | Defaults to “Swarvo AI”. |
| `PRODUCT_NEW_UI_ORGS` | Which existing customers may use the new interface: empty = nobody, `12,15` = those organization ids, `*` = everyone. | Optional | Existing customers cannot switch. New accounts made on the new site are never held back. |
| `PRODUCT_NUMBER_PROVIDER` | Set to `twilio` to buy from Twilio even when Plivo is configured. Otherwise Plivo is used if configured. | Optional | — |
| `PRODUCT_OPS_SECRET` | Secret for the every-minute scheduled job. | Required | The job route answers “not found” and webhooks, alerts, summaries and top-up links never run. |
| `PRODUCT_PLIVO_AUTH_ID` | Your Plivo auth id, used to buy numbers. | Optional | Plivo numbers cannot be bought. |
| `PRODUCT_PLIVO_AUTH_TOKEN` | Your Plivo auth token. | Optional | As above. |
| `PRODUCT_PRICE_SLABS` | JSON list of [minutes, rate] volume bands, for example `[[1000, 6.75], [5000, 6]]`. | Optional | Built-in default bands are used. |
| `PRODUCT_PROFILES` | JSON map from `default`, `fast`, `balanced`, `smartest` (and voice engines) to model profile names. | Required | Agents show “calls aren’t set up” and cannot go live or take practice calls. |
| `PRODUCT_SAMPLE_DIR` | Folder where voice preview clips are cached. Default `/tmp/voice_samples`. | Optional | Previews are regenerated after each restart. |
| `PRODUCT_SELLER_ADDRESS` | Seller address printed on invoices. | Required for invoices | Invoices lack an address. |
| `PRODUCT_SELLER_GSTIN` | Seller GSTIN printed on invoices. | Required for invoices | Invoices lack a GSTIN. |
| `PRODUCT_SELLER_NAME` | Seller name printed on invoices. | Required for invoices | Invoices lack seller details. |
| `PRODUCT_SELLER_STATE` | Seller state code, used to choose CGST+SGST or IGST. | Required for invoices | Tax split may be wrong. |
| `PRODUCT_SESSION_COOKIE` | Name of the sign-in cookie. | Optional | Default `vocalis_session`. |
| `PRODUCT_SESSION_HOURS` | How long a sign-in lasts. Default 720 hours (30 days). | Optional | — |
| `PRODUCT_SMTP_HOST` | Mail server for outgoing email. | Required for email | No email is sent; features fall back to showing a link. |
| `PRODUCT_SMTP_PASSWORD` | Mail server password. | Required for email | As above. |
| `PRODUCT_SMTP_PORT` | Mail server port. Default 587. | Optional | — |
| `PRODUCT_SMTP_USER` | Mail server user. | Required for email | As above. |
| `PRODUCT_TWILIO_ACCOUNT_SID` | Your Twilio account id, used to buy numbers. | Optional | Real numbers cannot be bought with Twilio; sandbox numbers are used. |
| `PRODUCT_TWILIO_AUTH_TOKEN` | Your Twilio auth token. | Optional | As above. |
| `PRODUCT_VOICE_ENGINES` | Comma-separated voice engines to offer. Default `inworld,google`. | Optional | Only the listed engines’ voices appear. |
| `RAZORPAY_KEY_ID` | Razorpay key id for customer top-ups. | Required for online top-ups | The top-up button is missing. |
| `RAZORPAY_KEY_SECRET` | Razorpay key secret. | Required for online top-ups | Top-ups fail. |
| `RAZORPAY_WEBHOOK_SECRET` | Secret that checks Razorpay’s payment notifications. | Required for online top-ups | The back-up payment confirmation is rejected. |

Also used by the platform and the web app: `OSS_JWT_SECRET` (sign-in secret, use 32+ random bytes), `DATABASE_URL`, `REDIS_URL`, `MINIO_PUBLIC_ENDPOINT`; on the old interface `NEXT_PUBLIC_VOCALIS_ENABLED` and `VOCALIS_URL`.
