The **Brain** tab sets how the agent thinks.

| Level | Best for | Trade-off |
|---|---|---|
| **Fast** | Simple, quick calls such as taking a message | Quickest replies, least depth |
| **Balanced** | Most agents | A good mix of speed and quality (the sensible default) |
| **Smartest** | Hard questions, longer reasoning, many tools | Most capable, may take a little longer to reply |

## Exact model (Advanced view)
In Advanced view you can pick a specific model from a list. An exact model you pick **wins over** the Fast / Balanced / Smartest level.

## When Brain levels do not apply
Agents using a **Google voice** run on one fixed model, so the levels do not change anything for them. Choose a Studio voice if you want to use levels.

## Cost
Your price per minute does not change with the Brain level. See [Volume pricing](/billing/volume-pricing/).
