On the agent's **Phone** tab you choose which numbers ring this agent.

- **Live numbers** attach only to agents that are live.
- **Test numbers** are sandbox numbers that attach to the test copy. They cannot receive real calls.
- Each number can have opening hours and an after-hours message.

See [Buy a number](/numbers/buy-a-number/), [Bring your own number](/numbers/bring-your-own-number/) and [Call hours and fallback](/numbers/call-hours-and-fallback/).
