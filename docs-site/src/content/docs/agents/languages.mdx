An agent can be set up with **up to 6 languages**. If you try to pick more, you will see "Pick up to 6 languages."

## How to set languages
1. Open the agent's settings and find **Languages**.
2. Choose the languages callers use.
3. Choose a [voice](/agents/voice/) that speaks them. Voices are tagged with a language; filter by language when choosing.

## What to expect
- Write your instructions in plain language and tell the agent which languages it may use.
- Put key words (names, places, product names) in **Words it should get right** under [Human feel](/agents/human-feel/).
- Always [try a call](/agents/test-your-agent/) in each language you promise.

:::caution
Quality varies by language and voice. Test each language before you go live.
:::
