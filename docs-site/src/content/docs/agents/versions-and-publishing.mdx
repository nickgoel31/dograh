You edit your agent on a private draft. Callers reach the **live** copy.

## Go live
1. Open the agent's **Publish** tab.
2. Read the checklist. Items marked as blockers must be fixed first. Items marked as warnings are optional but worthwhile. The agent needs at least a prompt (blocker), a business name (warning) and a voice (warning).
3. Press **Go live**.

Going live again later publishes your newest changes.

## Version history
Older versions are kept. **Restore** makes the chosen version your working draft. Nothing goes live until you press **Go live** again, so restoring is safe.

## Pause
An agent can be paused. Callers to a paused number hear a short message instead of the agent.
