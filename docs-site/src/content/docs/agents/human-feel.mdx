**Human feel** controls how the agent paces, listens and speaks. Studio voices support all of these. Interruptions, call length and silence timeout apply to every voice. Anything you leave unset keeps the voice's own default.

| Setting | Choices | What it changes |
|---|---|---|
| **Speaking pace** | 0.75 to 1.75 | How fast the agent talks. Lower is slower and calmer. |
| **How long it waits for you to finish** (patience) | Quick, Balanced, Patient | How long the agent waits before assuming you have finished. Quick can cut people off. Patient suits people who pause to think. |
| **Knowing when you have finished** (turn-taking) | Smart, Fast | Smart listens to the meaning of what was said. Fast reacts to silence. |
| **Delivery** (steadiness) | Steady, Expressive | Steady is consistent. Expressive sounds livelier. |
| **Natural fillers** | On / Off | Short "mm-hm" and "okay" sounds while thinking. |
| **Callers can interrupt** | On / Off | Whether the agent stops talking when the caller speaks. |
| **Words it should get right** | Up to 300 characters | Names, places and products, comma separated. Helps the agent hear them correctly. |

## Related limits
- **Longest call:** 1 to 60 minutes (default 15).
- **Hang up after silence:** 5 to 60 seconds (default 10).

See [Behavior and limits](/agents/behavior-and-limits/).

:::tip
Change one setting at a time and [try a call](/agents/test-your-agent/) so you can hear the difference.
:::
