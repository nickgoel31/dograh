The **Personality** tab tells the agent who it is and how to behave.

## Simple view
Fill in:
- **Agent name.**
- **Business name.**
- **What you do.**
- **Tone.**

Swarvo AI turns these fields into the agent's instructions. When you change a field, the instructions are rebuilt automatically.

## Advanced view
Switch on **Advanced view** to write the full instructions yourself. From then on the agent uses **custom** instructions and later changes to the simple fields will not overwrite them. To go back, restore an earlier [version](/agents/versions-and-publishing/).

## Tips for good instructions
- Say what the agent should do and what it must never do, such as quoting prices you did not give it.
- Keep answers short: callers are listening, not reading.
- Put facts in [Knowledge](/agents/knowledge/), not in the instructions.
- Always [try a call](/agents/test-your-agent/) after changing instructions.

## Variables
Call details such as the caller's name can be used in instructions where the editor offers them. Campaigns can pass extra columns from your CSV to the agent ([Campaigns](/conversations/campaigns/)).
