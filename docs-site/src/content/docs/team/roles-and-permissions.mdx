Every person in a workspace has one role. A person can have a different role in each workspace they belong to. The server checks the role on every action, so hiding a button is never the only protection.

| Permission | Code name | Owner | Admin | Developer | Viewer |
|---|---|:---:|:---:|:---:|:---:|
| See agents, calls, billing summary and settings | `read` | Yes | Yes | Yes | Yes |
| Create and edit agents, voices, knowledge, numbers, campaigns | `agents.write` | Yes | Yes | Yes | No |
| Create and edit tools and connections | `tools.write` | Yes | Yes | Yes | No |
| Create and revoke API keys | `api_keys.manage` | Yes | Yes | Yes | No |
| Add, test and resend webhooks | `webhooks.manage` | Yes | Yes | Yes | No |
| Invite people and change roles | `team.manage` | Yes | Yes | No | No |
| Add money, change spend limits and billing details | `billing.manage` | Yes | Yes | No | No |
| Delete the workspace | `workspace.delete` | Yes | No | No | No |
| Create sub-accounts | `workspace.create_child` | Yes | Yes | No | No |

In short: **Owner** can do everything. **Admin** can do everything except delete the workspace. **Developer** builds things (agents, tools, keys, webhooks) but cannot manage the team or billing. **Viewer** can only look.
