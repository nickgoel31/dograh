| | Simple | Advanced |
|---|---|---|
| Who it suits | Most people | People who want full control |
| Agent instructions | Fields (business, what you do, tone) | Write the whole prompt yourself |
| Brain | Fast / Balanced / Smartest | Also pick an exact model |
| Other settings | The basics | Every option |

## How to switch
Use the **Advanced view** switch in the top bar. It changes what you see, not what your agents do.

## Good to know
- If you write your own instructions, the agent switches to **custom** instructions. Later changes to the simple fields (business name and so on) will not overwrite them.
- Switching back to Simple deletes nothing.
