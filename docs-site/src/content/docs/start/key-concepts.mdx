| Term | Meaning |
|---|---|
| **Workspace** | Your business account. It holds your agents, numbers, money and team. You can belong to several. |
| **Agent** | One AI assistant with a job, a voice and its own instructions. |
| **Call flow** | The steps an agent follows during a call. See [Call flow editor](/agents/call-flow-editor/). |
| **Test and Live** | Each workspace has two sides. **Test** is a private copy where you build and try things for free. **Live** is what real callers reach. |
| **Go live** | Copies your agent from Test to Live. Callers then reach the new version. |
| **Wallet** | Your prepaid balance in rupees. Live calls take money from it. |
| **Minutes** | Calls are billed per minute, rounded up. A 61-second call is 2 minutes. |
| **Template** | A ready-made starting point for an agent. There are [13](/agents/templates/). |
| **Knowledge** | Documents, pages and answers your agent looks things up in while talking. |
| **Tool** | Something the agent can do during a call, such as book an appointment. |
| **Connector / integration** | A link to another service such as Google Calendar or HubSpot. |
| **Practice call** | A call you make to your own agent from the browser to try it. |
| **Brain** | How capable the AI is: Fast, Balanced or Smartest. |

## Test versus Live
- Test calls run only in your browser. They never reach real people.
- Campaigns and buying numbers work only in Live.
- API keys starting `sk_test_` see Test data. Keys starting `sk_live_` see Live data.
- Data in each side is kept apart. See [Data separation](/team/testing-vs-live-and-isolation/).
