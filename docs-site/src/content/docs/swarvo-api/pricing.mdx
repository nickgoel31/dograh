The more speech you generate in a month, the lower the price per minute of speech. Prices are in rupees and shown without tax.

| Minutes of speech in a month | Price per minute |
|---|---|
| 0 to 1,000 | ₹2.00 |
| 1,000 to 5,000 | ₹1.60 |
| 5,000 to 15,000 | ₹1.30 |
| 15,000 to 50,000 | ₹1.00 |
| 50,000 and above | ₹0.80 |

:::caution[Check before you rely on it]
These steps come from the app's pricing page, where they are defined in the front-end code, not from the billing code. Swarvo TTS 3 is also marked coming soon. Confirm prices with Swarvo before you quote them.
:::

## Voice agent calls
Calls where an agent speaks with a Swarvo voice get a cheaper minute: **20% less** by default. The host can change this (0 to 90%). See [Volume pricing](/billing/volume-pricing/) for the normal per-minute price.
