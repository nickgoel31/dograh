- **Articles.** Short guides with keyword search on topics such as getting started, phone numbers, billing, voices, knowledge, tools, campaigns, analytics, the Testing Lab, the API, webhooks, team, privacy, two-step sign-in and the website widget.
- **AI Helper.** The round button at the bottom right. It answers only from the Help articles. If no model is available it shows the best matching article.
- **Status.** Shows whether the database, AI models, payments and phone numbers are set up. It reads configuration; it does not test outside services.
- **Contact form.** Sends a message to your host's support.

The same topics are covered, in more detail, in these docs.
