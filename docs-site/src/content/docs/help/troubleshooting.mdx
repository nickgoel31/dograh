| Problem | Likely cause | What to do |
|---|---|---|
| Agent does not answer | Not live, number not attached, outside opening hours, paused, spend limit or balance | Check the Publish tab, the number's agent, [call hours](/numbers/call-hours-and-fallback/) and [Billing](/billing/how-billing-works/) |
| Voice sounds wrong | Wrong voice or pace | Change the [voice](/agents/voice/) or [pace](/agents/human-feel/) |
| Call dropped | Longest call or silence timeout reached | See [Behavior and limits](/agents/behavior-and-limits/) |
| Number not ringing | Incoming-call address not set (own carrier) | See [Bring your own number](/numbers/bring-your-own-number/) |
| Payment not credited | Payment still confirming | Wait a few minutes then contact support |
| Integration will not connect | Wrong details or permissions | See the integration's page |
| Try a call fails | Calling not set up for your workspace, or no model | Contact support |
| Practice call closes immediately | Microphone blocked or site not allowed | Allow the microphone; contact support if it persists |
