## Could not confirm from code
- **API trigger:** how a call started from the trigger address is authenticated with a Swarvo AI key. The platform's own docs use an `X-API-Key` header and a different key format. The page is marked "not fully verified".
- **Starting outbound calls through the public API:** not available (read-only), per `docs/API.md`.
- **Widget events / SDK:** no JavaScript event API is documented for the product's widget.
- **Phone number countries and rent:** which countries are offered depends on the host's carrier account. Prices default to "-" unless the operator sets `PRODUCT_NUMBER_MONTHLY_LOCAL` / `_TOLL_FREE` (those names are mentioned in `docs/RUNBOOK.md` but not found by the code search; check).
- **Fallback number:** stored but, per `PRODUCT_ASSUMPTIONS.md`, was not used yet; later commits may have changed this.
- **Refund policy, support hours, status page:** placeholders.
- **Voicemail choices** (leave voicemail / hang up / try again) come from the Behavior tab in the app source; whether the real build saves them was not checked.
- **Lighthouse scores:** not measured (the tool failed to launch in this environment). Accessibility was checked only by structure, not by an audit.
- **Tests with real providers, real calls, real payments:** none run, as the product's own notes say.
- Spell-check passes with a custom dictionary; US/UK spelling is mixed ("customise", "authorisation" are accepted).

- `docs/PRODUCT_ASSUMPTIONS.md` still says "no email is sent anywhere" and "8 templates"; code sends email (`emailer.py`) and has 13 templates. The docs site follows the code.
- `docs/SECURITY_NOTES.md` says there is no reset-password flow; `scripts/setup_email.sh` says it enables "password reset". Not checked which is true.
- `docs/PRODUCT_ASSUMPTIONS.md` says IP allow-list, SSO and custom branding are "Coming soon" in an older note; code now has allowed networks, company Google sign-in and branding fields.

## Bugs found

- `vocalis-web/src/config/brand.ts`: `PRICE_PER_MIN = 6` and the demo Billing page says "One simple price: ₹6 per minute, everything included", which contradicts the volume bands in `api/product/pricing.py` (first band ₹6.75). Real mode may differ; demo screenshots show the ₹6 text.
- `vocalis-web/src/config/brand.ts` tagline is "Voice agents that just work"; the requested docs tagline is "Voice agents that answer every call".
- `vocalis-web/src/pages/Developers.tsx:40` (demo) shows `data-color` and a fake CDN address in the widget snippet; the real snippet (`PlatformReal.tsx:106`) uses `data-app`, `data-agent`, `data-mode`.
- `api/product/export_openapi.py`: generating with every router produced duplicate operation IDs when the lab router is added twice (docs script avoids this).
- Starlight prints a harmless "Entry docs → 404 was not found" warning at build; adding a 404 page of our own conflicts with the built-in one.
